# 🚚 QuickSwift Logistics API

A simple Parcel Tracking & Delivery Management REST API built using **FastAPI and Pydantic**.

## 🚀 Features

- Create, view, update and delete parcels
- Pydantic `Field()` validation
- Custom validation using `field_validator`
- Nested `Address` model
- Duplicate tracking ID validation
- Parcel status filtering
- PATCH-based partial updates
- Business logic validation for parcel status
- HTTPException error handling
- Swagger API documentation

## 🛠️ Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn

## 📌 Parcel Status
Booked → Picked Up → In Transit → Out for Delivery → Delivered
